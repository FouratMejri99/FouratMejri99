# Core Network Engineer

## 🛠️ Tech Stack  

### 📡 Core Network Technologies (Telecom)
**Circuit Switched (CS) Core:** MSC, MSC Server, MGW, VLR, HLR, STP, SS7  
**Packet Switched (PS) Core:** SGSN, GGSN, PGW, SGW, MME, PCRF, PCEF  
**IMS / VoLTE / VoWiFi:** HSS, CSCF (P/S/I), MRF, TAS, IMS-AGW  
**Messaging & Legacy:** SMSC, USSD Gateway, IN/CAMEL, OCS/CDR Charging  
**Signaling Protocols:** SS7 (MAP, CAP, ISUP), Diameter, SIP, SIGTRAN, GTP  
**5G Awareness:** AMF, SMF, UPF, UDM, N1/N2/N4 interfaces  

### 🌐 Transport & IP Networking  
**Routing & Switching:** BGP, OSPF, IS-IS, MPLS, VLANs, STP (Spanning Tree)  
**Technologies:** IP/MPLS, SD-WAN, QoS, VPN (IPSec, GRE)  

### 🖥️ Platforms & Vendors  
**Telecom:** Ericsson, Nokia, Huawei, Cisco (ASR/NCS), Netscout  
**Enterprise Networking:** Cisco (IOS, IOS-XR, NX-OS), Juniper (JunOS)  

### 🔒 Security  
Firewalls (Palo Alto, Fortinet) • ACLs • Signaling Firewall (SS7/Diameter) • Zero Trust
